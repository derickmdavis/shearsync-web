# Root & Foil Ops

The frontend-only MVP for the internal Root & Foil Operations workspace, intended for `ops.rootfoil.app`.

It uses typed local mock data only—there is no authentication, API, database, billing, messaging, or analytics integration.

## Run

`npm run dev:ops` starts the app on port 3002.

## Future backend integration

- Authentication and internal roles
- Accounts, subscriptions, and account health
- Revenue and billing events
- Health metrics and customer insights
- Messaging delivery health and scheduled sends
- Automation definitions, runs, and failures
- Alerts and recent activity
